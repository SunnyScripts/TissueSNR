# Tissue Signal to Noise Solver
**Measuring the Bioelectric Signal-to-Noise Ratio in Non-Neural Tissue**

![Application GUI Image](app_image.png)

This project aims to bridge the gap between **Bottom-Up Single-Cell Omics** and **Top-Down Morphogenetic Bioelectrics** by simulating bioeletric networking using atlas defined gene kinetics.

## Pre-Processing

* RNA Velocity and Noise Using Raw Sequencing Data with SDEVelo 
* Cell Type Classifier
* Waddington Optimal Transport

## WGPU Spatial Solver

* Bioelectrics & Ion Diffusion (Fast)
* Gene Kinetics & Polarity (Medium)
* Morphology Delta (Slow)
